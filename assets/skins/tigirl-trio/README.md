# 虎娘三款插画皮肤

对应用户提供的三个设置界面预览：虎纹奶油、蜜桃虎娘、元气虎娘。
素材由内置 image_gen 根据预览图整理为透明、无文字的独立背景；提示词保存在 generation.json、compact-generation.json 和 compact-energy-fix.txt。
源 PNG 保留原始透明度，不把示例候选文字、编号或说明印在图片上。

运行 `python3 tools/build_tigirl_trio_ssf.py` 可重复生成项目 `皮肤/` 下的三个 SSF 包。
包使用普通 ZIP，包含 skin.ini 和 panel.png；针对当前虎娘渲染器配置了 H1、V1、H2、V2。
支持横排带编码、竖排带编码、横排无编码、竖排无编码、仅编码。
未宣称在搜狗输入法中验证兼容性。

字体由设置窗口选择；200 为紧凑源画布布局基准字号，设置中的字号将整个皮肤等比缩放。
当前包使用 *-compact.png，原始大面板 PNG 保留作设计参考。
设置字号 17、100% DPI 下，最小宽度约 151–153 像素（旧版约 257）。
横排无编码和仅编码只保留一行内容高度；带编码及竖排随内容增高。
在紧凑版基础上，字号 17 时上下内边距各增加约 8 像素、左右各增加约 7 像素，避免文字贴边。
候选增多或文字变长时，中间区域扩展，右上角角色及边角装饰保留原比例。
这是静态插画皮肤，没有角色逐帧动画。
首选候选通过主题文字颜色区分；原预览的整行高亮、独立编号色块不属于这套 SSF 当前支持的绘制内容。

安装：将三个 SSF 文件复制到 `%LOCALAPPDATA%\Tigirl\皮肤`，在候选外观页面刷新皮肤列表后选择。
不修改用户当前选择的主题或其他设置。

验证：当前虎娘原生 SSF 渲染探针覆盖三款皮肤 × 五种模式 × 三种内容状态 × 四档 DPI，
共 180 个新皮肤用例，并检查空码位置、候选点击区域、透明像素和字号/DPI 等比缩放。
