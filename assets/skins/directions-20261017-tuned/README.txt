布局
insets 为单独编码/单独候选页的上、下、左、右边距。
combined_insets 为编码与候选同时显示时的外边距；缺省使用 insets。
code_insets / candidate_insets 可分别覆盖独立布局，缺省使用 insets。
本批横排单行文字往纸面中央排，两行文字单独安排起点与下边距。
竖排给顶部装饰、底部花灯/水纹/按键和右侧角色保留安全边距。

stretch_horizontal / stretch_vertical 是 SSF 原生三元组：
  [模式, 前端固定长度, 后端固定长度]
模式 0 拉伸，1 平铺；两端之间是实际可伸缩区。不是候选窗固定尺寸。
三款人物均位于固定区域；主要饰物避开伸缩区。雨竹顶部连接枝、底边水纹
等背景笔触会随中部延展，人物、独立水滴和主体竹叶保持固定。
旧版仅指定 stretch=[x,y] 的定义仍支持，按原来的单像素切片处理。
