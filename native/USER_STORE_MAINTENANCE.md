# 用户词库维护

新构建的 `schema_select.exe` 提供显式维护命令（尚未部署到当前安装目录）：

```text
schema_select.exe <用户目录绝对路径> <内置码表绝对路径> --compact-user <方案名>
schema_select.exe <用户目录绝对路径> <内置码表绝对路径> --recover-user <方案名> <备份绝对路径>
```

内置方案名为 `虎码字词`，对应 `user/tiger-words.tcu`；其他已安装方案对应
`schemas/<方案名>/user.tcu`。命令使用方案当前的码表代，不切换当前方案，也不改配置。

输出 JSON 的 `changed` 表示是否完成替换或恢复。压缩返回 `false` 表示没有可缩减的
历史或文件正被旧客户端占用；恢复返回 `false` 表示主日志已经存在。错误退出码为 1。

压缩保留 `<日志名>.compact-<临时名>.old` 备份。恢复仅接受同目录、同日志名的完整
备份，不覆盖已有主日志，也不删除备份。备份可能早于后续输入调整，选择它并不等于
找回所有最新修改；目前不自动选择备份。

新构建的方案管理窗口已提供“整理词库”按钮，作用于列表中选中的方案，通过后台
任务执行；完成后说明结果及备份保留情况。按钮的可见布局和鼠标操作尚待验收。

“恢复词库…”按钮会打开备份文件选择窗口，默认定位到选中方案的用户词库目录，
仅接受 `.old` 备份。底层仍会校验归属和完整性，已有主日志不会被覆盖。隐藏窗口的
恢复操作已通过验证，文件选择器和可见界面操作尚待验收。

自动压缩、部分发布失败的自动恢复和备份保留期限仍未实现。
可重复的隔离验证：`python3 tests/user_store_maintenance_cli.py`。
加 `--manager` 可验证隐藏管理窗口的整理、恢复命令处理和布局边界。
