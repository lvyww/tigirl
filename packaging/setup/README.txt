虎娘 / Tigirl 图形安装程序

分发文件：虎娘-版本号-x64-x86-安装程序.exe。
双击单文件安装程序，按中文向导操作，无需手工解压。
只支持 Intel/AMD x64 Windows 10 1809（含 LTSC 2019） 及以上，包含 x86 程序支持。
不适用于 ARM64 和 32 位 Windows。

用户数据固定在 %LOCALAPPDATA%\Tigirl：
码表、拼音反查码表、config.txt、schemas、user 和 backups。
已有设置与个人词条保留。默认码表按 installed-data-baseline.json 中的安装基线判断：缺失文件正常安装，仍与基线一致的文件自动更新（即使新版内容相同也可以重写）；用户修改过或没有可信基线的现有文件保留，不弹出隐藏的冲突选择窗口。旧用户第一次升级到此机制时，不会把现有文件自动认定为未修改。缺失文件按补回处理，不记录主动删除意图。
不读取或迁移安装目录外的旧版目录；首次使用从安装包初始化 Tigirl 数据目录。

每次安装（包括同版本重装）都会创建独立的随机编号版本目录，完整解压、复制和校验，不共享跨版本资源。新版注册及机器级提交完成之前失败，恢复旧注册；提交成功后不再永久保留上一版用于回退，旧版受管文件统一登记为重启删除，不提前拆除旧进程可能继续使用的文件。退出旧程序不会立即完成这些清理。重启前连续升级可能暂时保留多份。

提交后的用户码表初始化失败只恢复用户数据及基线，不回退已经提交的程序。删除登记失败或重启后仍残留的文件，会凭 retired 目录中的小型清单在后续安装、恢复或卸载时重试。归属不明的文件不会递归强删；安装目录中被手工修改的打包文件会保留，并另备份到 Program Files\Tigirl\preserved，避免被旧版卸载记录误删。不要手工删除 maintenance 后端目录。

安装完成后请重开微信、Word 等程序。从开始菜单“虎娘 → 输入设置”调整设置。
以管理员身份直接启动安装时，用户初始化可能暂缓到日常账号下一次登录。

卸载：在 Windows“已安装的应用”中选择虎娘。
默认保留用户数据。勾选删除当前用户数据后，需要再次确认；包括该目录中的备份。
其他账号和旧外部码表目录不会删除。无法确认原用户身份时禁止删除数据。
直接运行安装根目录 unins000.exe 始终保留数据。
卸载以撤销 Tigirl 注册为提交点：manifest/install.json 损坏时仍会尽量解除属于 Program Files\Tigirl 的注册，并保留无法确认归属的残余文件；如果注册指向安装目录外的未知 DLL 才会停止。部分程序文件正在使用时会延迟到重启清理，不会强制关闭应用。

安装/卸载后端日志固定保存在 %ProgramData%\Tigirl\Logs\setup.log，不随安装目录删除。安装向导“打开日志”会优先打开该文件，若后端日志尚未创建则打开 Inno Setup 自身日志，并在打开失败时显示实际路径和错误码。当前用户初始化阶段另写 %LOCALAPPDATA%\Tigirl\setup-initialize.log，可区分冲突扫描、数据复制和编译等待。
此测试包未代码签名。真实 Intel/AMD x64 Windows 的多用户、UWP 及重启卸载验收仍需完成。
