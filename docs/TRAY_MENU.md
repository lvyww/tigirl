# 任务栏右键菜单

目标是在原生 TSF 的任务栏“中/英”按钮上接入虎爪式操作菜单。参考原版
`next/TigerClaw.Overlay/StatusWindow.xaml` 及其菜单处理代码。

- 虎爪 Github 页面：打开原项目页面。
- 方案文件夹：打开当前方案的源目录；没有源目录时打开原生缓存目录。
- 导出码表：将当前主码表与用户加词、删除、调序合并导出为 UTF-8 文本，
  存入 `%LOCALAPPDATA%\Tigirl\码表导出`。每次生成独立文件，不覆盖源文件。
  这是主码表导出，不包含补充语料、反查表或设置备份。
- 重载码表：调用现有方案管理的重新加载流程，保留用户词库。
- 加词：打开现有加词窗口，并带入最近输入历史。
- 方案：列出源文件夹与已准备的原生方案，勾选当前方案；选择后自动准备并切换。
- 主题：直接选择九种现有主题，并勾选当前主题。
- 输入设置：打开设置窗口。

菜单不再提供“切换到英文”；中英文切换继续使用任务栏按钮或原有快捷键。

任务栏弹出菜单与 TSF `InitMenu` 使用同一份菜单数据。源目录或配置变化在下次
打开菜单时重新读取。导入、导出等操作由短时管理进程执行，不在按键编辑锁中运行。
安全输入上下文不提供管理入口。

实现与验收记录：

- `tests/tray_menu_actions_test.py` 验证隔离配置下的主题、方案切换、重载和导出。
- `tests/run_management_menu.ps1 -Arm64X -DirectActions` 验证实际 TSF 菜单层级、
  主题勾选与管理窗口入口；不代表真实任务栏点击验收。
- `tests/run_management_menu.ps1 -Arm64X` 检查弹出菜单选择、窗口启动和焦点返回，
  会向独立测试窗口发送按键。

已安装版本 `dc8185042a242e42` 及匹配的32位组件。ARM64、x64、Win32
菜单接口和管理入口检查通过；ARM64 弹出菜单选择与焦点返回检查通过；主题、
方案切换、重载、含用户词的导出检查通过。安装后的全部文件哈希、双注册视图和
共享资源硬链接已核对，证据见 `build/tray-menu-installed-audit.json`。
这些是独立原生 TSF 宿主与短时管理进程的自动检查；尚未观察用户亲自点击任务栏。
更新后，重新打开输入应用即可加载新版 DLL。

候选窗右键复用同一菜单模型与命令分发。候选窗作为弹出菜单的 owner，
该入口不激活临时窗口；任务栏入口保留原有独立 owner 路径。
