# 方案内的可编辑用户数据

每个方案的个人数据统一位于 `%LOCALAPPDATA%\Tigirl\码表\<方案名>`，内置“虎码字词”也采用相同规则。

| 文件 | 内容 |
| --- | --- |
| `用户调整.txt` | 手动加词、删除、置顶、前移记录 |
| `自学习-虎娘.txt` | 整句自学习记录 |
| `补充语料.txt` | 用户手动设置的补充语料及权重 |

两个文件都是 UTF-8 文本，字段用真正的 Tab 分隔，可以用文本编辑器修改。支持 UTF-8 BOM、Windows 换行、空行和以 `#` 开头的注释；末行可以不带换行。没有需要手动重新计算的校验码。

编辑前请关闭使用虎娘的应用，避免编辑器保存旧内容时覆盖其他应用刚产生的记录。保存后执行“重载码表”或重新打开应用。错误格式会被拒绝，原文件不会被自动截断或覆盖；修正后可重新加载。不要在运行期间删除 `.lock` 文件。

## 加词和调序

使用虎爪的中文操作标记，紧接编码，再用 Tab 分隔词条。读取时也支持空格分隔；词条内的空格须写成 `\s`。操作按从上到下的顺序执行。

```text
# {操作}编码<Tab>词条（下面的分隔是真正的 Tab）
{添加}ab	虎娘
{置顶}ab	虎娘
{前移}ab	其他候选
{删除}ab	不再需要的词
```

- `{添加}`：添加词条至该编码末尾；同一上屏文字已存在时先去重。
- `{删除}`：删除该编码下对应上屏文字的候选。
- `{置顶}`：将该词置顶；不存在时可加入首位。
- `{前移}`：把已有候选向前移动一位。

删除某行表示不再执行该条操作，并不一定直接删除一个词：如果原始码表或后面的行还有相同词条，它仍可能存在。需要明确删除时使用 `{删除}`。

普通中文直接书写。空格写作 `\s`，反斜杠写作 `\\`，制表符写作 `\t`，Windows 换行写作 `\n`（读取为 CRLF，与虎爪一致）。虎娘额外支持 `\r` 和 `\u000a`，可分别保留单独的回车和 LF；特殊控制字符可写作 `\u001e` 等四位十六进制形式。修改显示／上屏分离词条时，应保留它原有的分隔标记。

## 自学习

新格式使用中文操作、ISO UTC 时间、明文片段／编码／前文和明确的“本次升级”。一条片段记录对应一次实际人工纠正，单次可升 1～3 级，累计封顶 10；不会用三条事件模拟一次跳三级。

文件格式、升级规则、补充语料子串识别和维护命令见 [Tab 纠正自学习](../TAB_LEARNING.md)。`python tools/learning_records.py "方案目录/自学习-虎娘.txt" show` 可以直接显示累计等级。不要在应用仍使用输入法时手工编辑记录。

## 缓存与旧数据

`schemas` 只负责方案编译版本、当前版本指针和源文件指纹等可重新生成的数据。用户调整不会被当作源码表再次导入，也不会因为每次学习／调序而重复编译原始码表。

本次不读取、不转换旧 `user/tiger-words.tcu`、`schemas/<方案名>/user.tcu` 、`.tigirl-learning.tsv` 或 `.tigirl-learning-v1.log`。磁盘上已有旧文件不会自动删除。新的个人记录只写入上述两个明文文件；不代表旧版留下的 `schemas` 已经自动清理。
