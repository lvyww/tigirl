# 自学习权重

当前自学习采用**人工纠错驱动的持久等级**，而不是使用频率或时间衰减模型。

只有用户把当前非首选候选主动改选为目标片段，并且该提交成功，才新增一次有效纠正。
学习后已经成为首选的普通空格、标点、回车等提交不再增加等级；自动提前上屏也不增加等级。
因此一个已经足够解决排序问题的偏好会稳定停在当前等级，不会因为重复输入而自行溢出。

同一编码与片段最多 10 级。跨上下文分数为：

- Level 1: +6
- Level 2: +8
- Level 3: +10
- …
- Level 10: +24

原纠正上下文保留额外约 +3 的保护，因此精确上下文分数为 +9、+11、+13……+27。
查询时取精确上下文分数与跨上下文分数的较大值。一次人工纠正就产生跨上下文偏好，
不再要求三个事件或两个不同上下文；单字片段使用同样规则。

学习没有时间衰减。事件时间戳只作为日志元数据，不参与评分。
同一编码、模式和上下文中，用户主动改选竞争候选时，旧候选有效权重乘以 0.25；
该变化同样只由新的人工纠正触发。有效权重按整数等级解释并封顶 10。

旧版日志中无法可靠区分真正人工纠正和“已学习首选正常提交”的 reinforcement。
因此新实现切换学习模式版本：旧日志文件继续保留，但旧模式记录不参与新模式打分，
避免历史自动强化被误计为新等级。

提前上屏置信度与排序分数分离。精确上下文分数 9、11、13 分别映射成熟度
0、0.5、1；首次纠正只改变排序，不增加学习型提前上屏置信度。

入口：`python tests/sentence_learning_test.py`；Windows MSVC 使用 `--cxx cl`。
测试使用隔离目录，不代表已安装版本或真实应用前台验收。
