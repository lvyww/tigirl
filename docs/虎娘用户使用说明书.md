# 虎娘用户使用说明书

适用于 2026 年 9 月 20 日版虎娘（Tigirl）。已有用户的设置可能与首次安装的默认值不同，请以“输入设置”中显示的内容为准。

## 一、第一次使用：照着做就能开始

1. 运行“虎娘-版本号-x64-x86-安装程序.exe”，按照中文向导安装。Windows 询问管理员授权时，点击“是”。首次安装需要准备码表，请等待完成。
2. 重新打开记事本等输入文字的程序。按 **Win + 空格**，选择“虎娘”。
3. 查看任务栏右下角的 **中／英** 状态，切换到“中”。
4. 右键点击“中／英”按钮，打开“方案”菜单，选择 **虎码字词** 或 **虎整句**。
5. 点击输入框，输入你熟悉的虎码编码，出现候选后按 **空格**确认。

**选哪个方案？** 想按字、词逐个确认，选“虎码字词”；想连续输入一段编码，让输入法组合成句子，选“虎整句”。虎娘使用虎码编码，整句模式并不是拼音输入。

如果任务栏菜单不方便打开，在候选窗上点击鼠标右键，也能打开管理菜单。开始菜单中的“虎娘 → 输入设置”也可打开设置窗口。

## 二、安装与更新

公开的 x64／x86 安装包适用于 **64 位 Windows 10 1809、LTSC 2019 及更新版本的 x64 Windows**，同时支持其中的 64 位和 32 位应用。它不适用于 32 位 Windows、Windows 7 或 ARM64 Windows；ARM64 设备需要对应版本。

更新时运行新版安装程序即可。新版会保护已有个人配置；默认码表文件若仍与上次安装的记录一致，可自动更新，用户修改过或无法确认来源的文件会保留。重要数据仍建议先备份。

安装后请重新打开需要使用输入法的应用。更新成功后，旧版本程序文件会安排在重启时清理；重启前磁盘占用可能暂时增加。

## 三、最常用的操作

| 操作 | 怎么做 |
| --- | --- |
| 切换到虎娘或其他输入法 | 按 Win + 空格 |
| 中英文切换 | 点击任务栏“中／英”；启用 Shift 切换时，也可单按并松开 Shift |
| 确认候选 | 普通字词模式按空格选首选；整句模式按空格确认当前选中的候选 |
| 按编号选字词 | 普通字词模式按候选前的数字；改过选重键时按自己的配置 |
| 修改未确认的编码 | 按 Backspace 逐个回删 |
| 放弃本次输入 | 按 Esc，清除尚未上屏的编码和候选 |
| 翻页 | 普通字词模式默认用减号／等号；可在“输入行为”中修改 |
| 打开管理菜单 | 右键点击任务栏“中／英”或候选窗 |
| 调整候选字号 | 鼠标放在候选窗上，滚动滚轮 |

“上屏”就是把文字正式输入到当前应用中。已经上屏的文字，不能再通过 Esc 撤销；需要在应用中删除或修改。

**关于 Ctrl + 空格：** 首次安装默认不由虎娘额外处理此组合键，实际效果取决于 Windows 的快捷键配置。想稳定切换，可先用“中／英”按钮或 Shift。

**关于回车和 Tab：** 它们不是所有模式下都等于“确认”。回车受“回车清空编码”设置影响；普通字词模式下 Tab 可清空编码，整句模式下则用于选候选。新用户先用空格确认、Esc 取消最容易掌握。

## 四、使用虎整句

虎整句把连续输入的单字编码交给本地模型切分、组合和排序。建议先熟悉虎码单字编码，再练习整句输入。它使用本地 n-gram 模型，不需要联网，也不需要配置 Qwen。

### 1. 连续输入的基本规则

切换到“虎整句”后，连续输入每个字的编码，**字与字之间不按空格**。观察候选句，满意时再按空格确认。

记住下面几条，能减少“单字能打，放进句子却不对”的情况：

- **一简字放进长句时，至少输入两码。** 例如“一”使用 `fi`。
- **“的”使用特设编码 `ue`。**
- 默认对高频前 1500 个单字限制为最短首选码组句；其他字可以使用符合规则的非主码。
- 要允许某些高频字用全码组句，可在“整句输入”页的“允许全码组句的例外字符”中填写这些字。想取消高频字限制，把“仅使用最优码组句的高频字数量”设为 **0**。

候选窗中编码之间的切分空格只是阅读提示，不需要照着输入，也不会写入原始编码。

### 2. 同一个编码对应多个字词时

**选重后缀**就是在编码后面追加一个符号或数字，说明要用该编码的第几项：

| 后缀 | 含义 |
| --- | --- |
| `;` | 第 2 项，需启用“分号次选” |
| `'` | 第 3 项，需启用“引号三选” |
| 数字 | 指定该编码的第 N 项，例如 `2` 表示第 2 项 |

以下例子按配套整句码表说明，若自行修改过码表顺序，结果可能不同：

```text
hh2ah  → 慢慢来
b;ot   → 如果是
```

**整句模式中的数字是在给编码选重，不是选择候选窗中第几条整句。** 要切换整句候选，请用 Tab 或上下方向键，再按空格确认。

“允许单字重码组句”默认开启：即使没有追加选重后缀，非首选的单字也可以参与组句，由模型结合上下文排序。例如 `gyygch` 可以组合出“羊羔”，而不只是“羊赤”。但要注意：

- 单独输入一个编码时，仍优先显示码表首选。
- 非首选的**多字词**仍需要追加选重后缀。
- 此选项不会取消前面提到的高频字最优码限制和例外字符规则。
- 想明确指定某个字，仍可以追加选重后缀。

### 3. 用 Tab 选择并锁定

1. 当前候选不合适时，按 **Tab** 切换到下一项；**Shift + Tab** 往回切换。
2. 选中想要的内容后，继续输入**字母编码**，已选内容及其编码边界会锁定，后续组句不再改动这部分。
3. 如果这一段已经输入完，直接按 **空格**确认当前候选。

仅按 Tab 不会上屏。Tab 选好后再输入字母时，是否立即上屏取决于设置：

- **提前上屏开启：** 已确认部分立即上屏，继续输入后面的内容。
- **提前上屏关闭：** 已确认部分仍保留在尚未上屏的组合串中；回删到锁定边界，可解除该次锁定。

上下方向键也可以切换整句候选，但不等同于 Tab 锁定流程。Tab 之后输入数字、分号或引号等选重后缀，仍是在修改当前段，不会触发上述字母续写锁定。

### 4. 自动提前上屏是怎么回事

虎娘默认开启“自动提前上屏已确定的句子前缀”。模型连续判断某个开头足够稳定时，会把这部分先输入到应用，候选窗继续保留后面的活动编码。因此，打字过程中候选变短、前半句先出现在正文中，可能是正常行为。

如果希望整段都由自己确认，可在“输入设置 → 整句输入”中关闭它。回删或手动切换候选会重置或暂停当前的稳定判断，输入法不会单凭此前的判断一直往前提交。

重码单字也会参与提前上屏判断。例如 `ot` 对应“是／题”、`qm` 对应“目”时，输入法不能仅因为“是”排首位，就在输入到 `otq` 时把它当成唯一结果上屏。

已经上屏的部分需要在应用中修改；Esc 只取消尚未上屏的部分。如果出现重复上屏、漏字或明显闪烁，可先关闭提前上屏，并记录应用名称和完整按键顺序以便反馈。

### 5. 常用按键速查

| 按键 | 整句模式下的作用 |
| --- | --- |
| 空格 | 确认当前选中的整句候选 |
| Tab／Shift + Tab | 向后／向前切换候选，随后输入字母可锁定所选内容 |
| ↑／↓ | 切换整句候选 |
| 数字、分号、引号 | 为编码指定码表选重，不直接选择整句候选 |
| Backspace | 回删未上屏编码；关闭提前上屏时，回删到锁定边界可解除该次锁定 |
| Esc | 取消未上屏内容 |
| Enter | 未启用“回车清空编码”时提交原始编码；启用时清空，不作为确认整句的通用按键 |

### 6. 让输入法记住你的选择

打开“输入设置 → 整句输入”，找到 **“Tab 锁重上屏后自学习（仅本方案、本地保存）”**。

开启后，通过 Tab 纠正并最终确认上屏的选择，可用于调整以后候选的排序。不是每按一次 Tab 就立即学习；取消的输入也不等于确认。学习结果只保存在本机对应方案中，不会自动同步到其他电脑。关闭开关不等于清空已经保存的学习记录。

### 7. 用补充语料改善常用表达

经常输入的人名、专业词或新表达，若已有合法编码路径但排序不理想，可以加入补充语料：

1. 切换到“虎整句”，右键选择“方案文件夹”。
2. 打开或新建 **补充语料.txt**，以 UTF-8 编码保存，每行一个词条，可在后面用空格填写权重。
3. 保存后，在右键菜单执行“重载码表”。

例如：

```text
# 词条 权重
茧师 1000
新流行词
```

省略权重时按 **1000** 处理。补充语料只提升已有合法编码路径的排序，**不新增码表条目，也不改变普通字词模式**。如果根本没有对应编码，应使用加词或修改源码表；仅写进补充语料不能解决。

建议先添加少量常用词观察效果。常用单字会影响许多句子，不宜随意给单字设置很高的权重。

## 五、不会拆字时，用拼音反查

1. 确认处于中文状态，先清空正在输入的编码。
2. 按键盘左上角、数字 1 左边的 **反引号键**。
3. 输入拼音，例如 `ni`，查看候选及对应虎码提示。
4. 选择需要的字，或按 Esc 退出。

此功能需要启用“反引号键拼音反查”，并有可用的拼音反查表。它适合临时查询不熟悉的字。

## 六、调整外观和输入习惯

右键菜单选择“输入设置”。窗口分为五个标签页：

| 标签页 | 可以调整什么 |
| --- | --- |
| 输入行为 | 中英文切换习惯、标点、注释与拆分显示、最大码长、每页候选数量、翻页键等 |
| 候选外观 | 字体、字号、主题、候选和注释展开延时、窗口动效、编码伪装 |
| 操作快捷键 | 手动加词、最近方案切换、选重键 |
| 整句输入 | 整句启用、提前上屏、组句规则、自学习 |
| 赞赏 | 查看赞赏码 |

修改后点击“保存”。保存可能清除正在输入的编码，建议先完成当前输入再改设置。“取消”不保存本窗口的修改；独立选重键窗口中已保存的设置不受此影响。

候选太小，先调整字号；想换颜色，可直接使用右键菜单中的“主题”。不喜欢动画，可关闭“候选窗动效”。动效时间与候选展开延时是不同设置：前者控制过渡速度，后者控制候选内容的延迟展开。

“编码伪装”只改变编码的显示。例如填入 `●` 后，`ab` 显示为 `●●`，实际查码和上屏文字不变。留空关闭；它不是加密功能。

## 七、加词、码表与切换方案

**手动加词：** 在右键菜单选择“加词”，按窗口提示填写词语和编码并保存。也可在“操作快捷键”中查看或设置加词快捷键。

**切换方案：** 在右键菜单的“方案”中选择。首次使用新方案时，需要准备码表，可能比平时切换慢。

**修改码表：** 右键选择“方案文件夹”，打开当前方案的源文件目录。修改前先备份；保存后执行“重载码表”。文件必须符合虎娘支持的码表格式，不能把任意文本文件直接当成码表。

用户数据固定保存在：

```
%LOCALAPPDATA%\Tigirl
```

按 **Win + R**，粘贴上面的路径，再按回车即可打开。常用内容：

| 名称 | 用途 |
| --- | --- |
| 码表 | 各方案的源文件，每个方案一个文件夹 |
| 拼音反查码表 | 拼音反查的源文件 |
| config.txt | 个人设置 |
| schemas 等内部目录 | 编译码表和版本指针等内部缓存 |
| 码表导出 | 执行“导出码表”后生成的文件 |

新版把方案个人记录也放在“码表\<方案名>”中：`用户调整.txt` 保存加词、删除、置顶和前移；`.tigirl-learning.tsv` 保存整句自学习。两者都是 UTF-8 明文，中文直接可读，以 Tab 分隔字段。编辑前关闭使用虎娘的应用，保存后重载码表或重开应用。错误行需要修正，不会自动覆盖丢弃。

例如，在 `用户调整.txt` 中添加一行 `{添加}编码`、词语（两者用 Tab 隔开）即可加词；`{置顶}` 表示置顶，`{删除}` 表示删除，`{前移}` 表示前移一位。词语中的空格用 `\s` 表示。文件格式和自学习各列说明见同目录的 USER_DATA_FILES.md。旧版二进制记录不自动迁移。

**“导出码表”不是完整备份。** 它导出当前主码表及加词、删除、调序结果，不包含所有设置、补充语料、拼音反查表和学习记录。

## 八、备份、换电脑与卸载

**完整备份：** 先退出正在使用虎娘的应用，并关闭设置窗口，再把整个 `%LOCALAPPDATA%\Tigirl` 文件夹复制到安全位置。

**换电脑恢复：** 在新电脑安装兼容版本并完成首次初始化；关闭相关应用，先备份新电脑已有的 Tigirl 用户目录，再恢复原电脑的完整用户目录，最后重新打开应用。新版中，复制完整的“码表\<方案名>”文件夹可以带走该方案的源码表、加词、调序、自学习及补充语料；全局设置和共享拼音反查表仍需单独备份，推荐备份整个用户目录。

**卸载：** 在 Windows 的“设置 → 应用”中找到“虎娘”并卸载。默认保留用户数据，方便以后重新安装。若界面提供删除用户数据的选项，只在确定不再需要且已备份时选择。提示重启时，请重启完成被占用程序文件的清理。

## 九、遇到问题先这样检查

| 情况 | 先检查什么 |
| --- | --- |
| 输入的字母直接出现在文本框，没有候选 | 用 Win + 空格确认已选虎娘，再确认“中／英”为“中”；安装后重新打开该应用 |
| 只有某个应用不正常 | 先在记事本测试，再完全退出并重开出问题的应用 |
| 找不到设置或任务栏菜单打不开 | 从开始菜单打开“虎娘 → 输入设置”，或右键候选窗 |
| 选了虎整句，但仍不能组句 | 检查“整句输入”页是否启用按方案名称自动开启；确认安装包含模型，未自行移动或删除程序资源 |
| 输入途中有一部分文字先上屏 | 检查是否开启“自动提前上屏已确定的句子前缀” |
| 候选或注释过一会儿才展开 | 检查“候选外观”中的两项延时设置，以及注释显示是否开启 |
| 更新后磁盘占用变大 | 新旧程序目录可能暂时并存，重启后再看；模型本身也是主要占用来源 |
| 安装长时间停在准备码表 | 点击“打开日志”，保存日志并反馈；不要仅凭强制关闭后能打字就认定安装完成 |

反馈问题时，请附上：安装包版本、Windows 版本、出问题的应用、使用的方案、具体按键顺序。候选位置异常时，再说明显示器数量和缩放比例。截图或短视频通常更容易说明问题。
