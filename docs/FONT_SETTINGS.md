# 设置窗口与字体预览

字体选择改为下拉列表，参照虎爪 `TigerClaw.Dialog/ConfigWindow.xaml.cs` 的
`SetupFontEditor`、`AddFontItem`、`SelectFontComboByValue`、
`GetPreferredFontDisplayName` 和 `SyncFontComboPreview`。

- 优先列出管理程序旁“字体”目录中的 TTF 字体，名称带 `#` 前缀。
- 随后列出 DirectWrite 系统字体集合，按字体家族名称忽略大小写排序。
- 优先显示 zh-CN 名称，其次 en-US 名称；系统字体仍有其他名称时使用该名称。
- 显示名称忽略大小写去重，并接受原有英文家族名作为配置别名。
- 配置字体不存在时选择第一项；保留原生候选窗已有的默认字体和字号。
- 下拉列表的每一项使用自身字体绘制；选中框也使用选中字体，而非统一 UI 字体。
  使用 DirectWrite / Direct2D 绘制，并按窗口 DPI 缩放。
- 列表预览固定使用 14 DIP，只展示字体，不随实际字号变化。字号保存仍限定 3–200，支持小数。
- 选中框维持约28 DIP的固定高度，列表中的字体以固定字号显示。
- 保存写入所选显示名称（内置字体含 `#`），取消不改配置。

实现：`tools/FontChooser.{h,cpp}`、`tools/InputSettings.cpp`。
短时 ARM64 设置程序供 ARM64、x64 与 x86 TSF 安装共同使用，无常驻字体服务。

验证：`tests/input_settings_test.py` 检查已保存字号、字体顺序、去重、所有列表
别名匹配、缺失字体回退，以及原有保存/取消/并发字段保留检查。实际控件在独立
且未切换为输入桌面的 Windows desktop 上绘制，生成
`build/font-settings-{96,120,144,192}.png` 和 `build/font-dropdown-{96,120,144,192}.png`。
字体集合数量由本机字体决定；截图可检查各列表项按自身字体显示。

## 虎纹奶油设置窗口

设置窗口使用“虎纹奶油”外框，保留原生 Win32 控件和五个标签页。
完整外接矩形固定为 640×480 DIP（含虎耳、标题和底栏），不能调整大小或最大化。
100%、125%、150%、200% 对应 640×480、800×600、960×720、1280×960 像素。
工作区较小时不缩小；首次打开确保标题可见，可拖动标题，或用 Alt+Space → 移动。
标题栏提供最小化、关闭；Alt+F4 与取消均不保存。
页面按需纵向滚动，顶部标签与底部保存操作固定。按用户选择，设置控件不参与 Tab 导航，点击后不显示虚线焦点框；输入框与快捷键框仍可点击后输入。

- 输入行为：紧凑双列排列输入模式、标点、编码与上屏选项，不再显示分组标题。清屏表示清除未上屏编码。
- 候选外观：字体和字号同一行；主题及候选选项在左，实时预览与小虎娘在右；延时、动效与编码伪装紧接其下。
  字体与主题下拉框宽 160 DIP，字体展开宽 360 DIP，字号框 60 DIP；数值框按内容缩短。
  字号显示一位小数；未编辑字号时，保存其他选项不会改写配置原有精度。
  每页数量、注释、拆分都集中在此。示例区复用 CandidateRenderer，修改立即
  更新字体、主题和排列示例，不连接输入服务、不写配置。预览固定为 244×148 DIP、14 DIP 字号与三个示例候选；不随实际字号和候选数量缩放，不显示额外外框或比例说明。
  延时与动效不在示例中播放。各页补充说明移到对应控件的悬停提示中。
- 按键与快捷键：紧凑排列模式切换、反查、翻页、选重及操作快捷键。
  已移除 Ctrl+空格开关及引擎处理，完全交由 Windows；旧配置中的同名键保留但不生效。
  选重键编辑窗口独立保存，不受主设置窗口取消影响。
- 整句输入：取消分组标题，依次排列启用、提前上屏、组句及自学习选项。
  例外字符框支持多行自动换行，保存时移除换行，仍为单行字符列表。
- 赞赏：中央以约 250 DIP 显示原图，保留完整比例与赞赏码。

关闭动效、提前上屏或某项操作快捷键时，对应参数暂时禁用但保留原值。
注释与拆分同时关闭时禁用其延时。底部显示有无未保存更改。
校验失败会切页并滚动到错误字段，显示中文原因和范围。
保存并关闭后继续清除未完成编码、应用默认模式；无修改保存不写文件，
不发出刷新请求。取消保留配置；只合并修改字段，保留未知键、注释和其他进程修改。

回归使用 `tools/InputSettingsProbe.vcxproj` 直接调用生产窗口。
构建 Release ARM64，将内置字体放在 `build/tests/ARM64/字体/`，运行
`python3 tests/input_settings_test.py`。隔离桌面截图保存在 `build/`：
`input-settings-{96,120,144,192}.png`、`font-settings-*.png`、
`page-{1,2,3}-{top,bottom}-*.png`、`sentence-settings-*.png`、
`donation-settings-*.png` 和 `preview-large.png`。
测试检查滚动可达性、小窗口、依赖禁用与恢复、错误定位、预览不落盘、
无修改保存、保存后重开、取消、快捷键冲突、参数校验与并发字段保留。

文本框内容水平、垂直居中；多行内容超高时从顶部显示并可滚动。快捷键框保持原生按键捕获，文字采用居中绘制。

正文使用 14 DIP 黑体（SimHei），辅助说明使用 12 DIP；保存失败使用正文字号。

外框与透明插画由 `tools/SettingsSkin.{h,cpp}` 绘制：WIC 一次解码缓存，
Direct2D 复用位图与绘制目标。资源来自 `assets/settings/tiger-cream-ornaments.png`；
原始参考稿在 `design/settings-640x480/tiger-decor/01-tiger-cream.png`，生成提示词
保存在 `assets/settings/generation-prompt.txt`。虎娘大图只出现在候选外观页。
标签、复选框和按钮保留原生窗口类型、状态与通知，仅覆盖绘制；组合框、编辑框
和 Hotkey 框继续使用原生实现。高对比度隐藏图片，使用系统配色。
皮肤不写入候选主题，没有新增配置键；真实候选窗和独立选重键窗口不应用此皮肤。

验证边界：四档截图由同一隔离桌面中的实际 Win32 控件按相应 DPI 布局生成，
不切换用户输入桌面。`system-colors-*.png` 强制走高对比度的系统配色分支，
没有修改 Windows 全局高对比度设置，也不替代实体多显示器切换验收。
Hotkey 框保留原生录入，并居中绘制组合键；屏幕与 WM_PRINT 截图均显示组合键文字。
其设置值、冲突校验、保存和实际引擎分派另有自动化断言。

## 滚动重绘回归

滚动时先以 `SWP_NOREDRAW | SWP_NOCOPYBITS` 更新控件位置，再统一重绘父窗口、
子控件和输入框边框；父窗口裁剪子窗口区域。普通消息不再反复触发布局或把
手动滚动的位置拉回当前焦点，只在校验错误定位等必要情况下滚动。

`python3 tests/input_settings_scroll_test.py --active-desktop` 会短暂显示独立测试
窗口，连续上下滚动后直接读取屏幕像素，再与完整重绘后的画面对比。
它不使用 WM_PRINT 重建画面，因此能捕获实际留下的缺字和重影。
比较使用 `GetWindowRgn` 排除虎耳轮廓之外的桌面像素。四个设置页内部
必须零像素差异，且配置内容和修改时间不变。截图和报告保存在
`build/settings-scroll-capture/`。此测试需要可见桌面；常规隔离桌面测试仍单独运行。

## 实际屏幕与窗口生命周期验证

`python3 tests/settings_skin_test.py --active-desktop` 生成四档 DPI × 五页的完整
屏幕截图：`build/tiger-cream-validation/screen-{0..4}-{96,120,144,192}.png`。
测试固定外接尺寸、标题命中、最小化/恢复、关闭不保存、Space 勾选、
无 Tab stop、悬停提示注册、主题下拉框，并循环打开/关闭及切换 DPI，检查 GDI/USER 句柄。
这些 DPI 由生产缩放函数驱动；高对比度强制走系统配色分支，均不更改全局显示设置。
实体多显示器 DPI 迁移与 Windows 全局高对比度切换仍需人工验收。

标题栏右侧与底栏控件向内留边：底部按钮位于 428–456 DIP，状态提示位于 435–453 DIP，避免背景矩形覆盖虎纹边饰。

中间页面不再绘制独立的不透明圆角底板或边线；页面空白、标签、复选框和插画区共用窗口奶油底色，让两侧虎纹连续显示。输入框、组合框、按钮及原始赞赏码保留自身背景。


## 奶油色现代控件

`SettingsControls.{h,cpp}` 只为设置窗口装饰原生控件，不修改候选窗和独立选重键窗口。
采用 7 DIP 圆角、1 DIP 细描边和浅奶油底（#FFFAF0）；悬停或编辑时使用橙色边线，禁用控件使用较暗的奶油色。
按钮与复选框复用 `SettingsSkin::surface` 的 Direct2D 抗锯齿圆角，保存按钮使用橙色实底。

文本框移除 WS_EX_CLIENTEDGE，通过 WM_NCCALCSIZE 保留原生编辑区，为自绘边框留出内边距；
非客户区绘制排除原生文字区域，并用圆角窗口区域裁剪外角，避免露出方形背景。
原生选区、光标、撤销、输入法和修改通知继续保留。数值、伪装字符及例外字符仍居中。

下拉框保留 COMBOBOX、CBS_HASSTRINGS 和原生弹出列表，使用 owner draw 绘制列表项；
选择区域与小箭头由子类绘制。字体列表仍逐项使用相应字体预览，主题和翻页列表使用黑体。
页面与文本框的细滚动条绘制沿用 GetScrollBarInfo 的原生范围与滑块位置。展开后的组合框列表保持原生直角窗口，不再设置圆角区域；列表滚动条全部由原生控件绘制，避免静止时自绘、跟踪滚动时系统绘制造成配色切换。列表项仍保留奶油底色与暖色选中项。
提示框保留原生提示文字、悬停时序和位置，仅绘制奶油色圆角外观。
高对比度切换会同步刷新控件配色与窗口区域。

实现依据：[Win32 owner-drawn combo boxes](https://learn.microsoft.com/en-us/windows/win32/controls/about-combo-boxes)、
[WM_NCPAINT](https://learn.microsoft.com/en-us/windows/win32/gdi/wm-ncpaint)。

### 控件悬停重绘

按钮与复选框仅在悬停状态变化时主动请求刷新，鼠标在控件内部连续移动不再反复清空并绘制标签。`SettingsPaintBuffer.h` 将按钮、复选框、组合框、快捷键框和提示框的背景与文字绘制到内存位图，再一次性复制到目标 DC；全自绘控件不单独擦除背景。原生点击、勾选、输入及通知机制保持不变。

原生设置测试对四个按钮/复选框分别发送 100 次内部移动消息并处理重绘，断言没有额外 `WM_PAINT`，同时检查复选框点击仍然切换状态。

赞赏页在二维码下方居中显示“虎娘 · 版本 …”，版本号读取当前设置程序的 ProductVersion 资源，不参与配置保存。二维码仍保持 250 DIP 显示区域及原始比例。
