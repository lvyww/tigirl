# 紧凑整句排序先验

整句排序沿用有限的整段奖励、生僻字保护与词先验，不扩大字符 n-gram 模型或 Beam。

## 整段单字奖励（2026-10-09）

当整个输入一次匹配一个单字，且没有显式选重时，给予 `5.0` 分。
若该字属于用户设置前 N 个高频字、且不在全码白名单中，还必须匹配其最优码；
其余单字可使用现有码表中任一合法、完整匹配的编码。N 与白名单继续来自当前用户设置，
本次不改变默认值或已有配置。现有主码候选过滤规则不变，奖励不会让被过滤的编码重新入选。
词、句内分段、显式选重均不获得此项奖励。奖励仍从概率质量中扣除，不计入提前上屏置信度。

原先主码单字边的 `2.0 × 码长` 奖励已移除；旧调用方传入 `canonicalCodeReward` 也不再生效。
这使句内使用合法非最优码时，不会因其他拆分路径累计主码奖励而吃亏。

## 保留的排序先验

- 主码或显式选重的四码及以上单字免除孤立生僻字惩罚；
- 150,032 字节 TCSLEX01 Bloom filter 对原 Top-5 中命中的 2～4 字词提供
  `0.10 / 0.12 / 0.14` 的非重叠最大覆盖奖励。

生僻字保护只在终点评价，词先验只重排原 Top-5；两者均不进入 `confidenceScore`，
无 n-gram 模型时关闭。锁定前缀继续保留四码保护元数据，续输不恢复已移除的主码奖励。
自学习、纠错调频与提前上屏阈值沿用既有逻辑。

词先验共 50,000 条、10 次散列、1,200,000 bit，由资源线程从
`Models/sentence-lexical-v1.bin` 读取；缺失时退回无词先验排序，发布与安装预检则
要求其哈希精确匹配。来源、转换与许可见 `THIRD_PARTY_NOTICES.md`。
