# 紧凑整句排序先验

本实现同步自 `tiger-sentense-rime` PR #15，在不扩大字符 n-gram 或 Beam 的
前提下，为原生整句最终排序加入三类有界证据：

- 主码单字边按 `2.0 × 码长` 累计形码证据；
- 主码或显式选重的四码及以上单字免除孤立生僻字惩罚；
- 150,032 字节 TCSLEX01 Bloom filter 对原 Top-5 中命中的 2～4 字词提供
  `0.10 / 0.12 / 0.14` 的非重叠最大覆盖奖励。

形码证据不进入 Beam score，生僻字保护只在终点评价，词先验只重排原 Top-5。
三者均不进入 `confidenceScore`，因此不改变候选生成、提前上屏概率、学习奖励或
自动上屏阈值。无 n-gram 模型时三项全部关闭。锁定前缀会随路径边界保留形码分
和四码保护元数据，续输不会丢失先验。

词先验共 50,000 条、10 次散列、1,200,000 bit，由资源线程从
`Models/sentence-lexical-v1.bin` 读取；缺失时安全退回原排序，发布与安装预检则
要求其哈希精确匹配。来源、转换与许可见 `THIRD_PARTY_NOTICES.md`。
