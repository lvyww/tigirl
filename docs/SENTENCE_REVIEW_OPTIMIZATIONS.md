# 整句审查修复与等价优化

基准：`4f88a4eeffd07fa0cf26e5e26d04d2b760ab6c5b`。本次不改变模型、码表、默认 Beam 2000、学习权重、Unicode 字素定义或自动提交阈值；不修改候选窗和安装流程。模型格式仍为 TCSKNM01，学习日志仍为 TCL1，不需要转换模型或清空学习记录。

## 正确性修复

1. 显示候选与完整完成候选池分开。`confidenceCandidates` 是不可变共享快照，菜单只复制显示部分；普通提前上屏和空码强接受使用完整适用候选池。隐藏候选贡献概率，但不会被空码快捷路径直接选中；空菜单不解引用 `front()`。
2. 已发生的祖先 Beam 截断沿实际后继传播。最终层没有再次超宽，也不能恢复成“完整置信”。已截断或学习影响的分布不生成可提交的前缀证据；不完整尾码导致截断时也跳过无用的概率表构建。
3. 增量复用按真实最大码长和选重跨度判断完整输入边界，不再写死四码。词组资格和整码单字奖励不泄漏到句中。
4. 多位数字、分号、引号选重变化，以及跳过中间输入代后的缩短，走安全重建；不能假设删除后的状态一定算过。
5. 回删学习影响代重新计算学习标志，不把已删除路径的累计影响留给新输入。新增学习提示可能改变排序时也重新建立该代。

以上修复有意改变旧错误行为：自动提交可能延后，某些旧增量候选/分数会恢复成完整解码结果。因此不能要求所有旧自动提交记录逐项相同。性能等价测试与错误行为修复测试分开。

## 缓存、对象与内存

- 锁定与非锁定输入共用一套缓存生命周期，重复请求直接命中，安全追加/回删只处理受影响部分。缓存持有锁定对象，保证种子上下文 `string_view` 的寿命。锁定变更、学习快照切换、中间编辑及不安全选重仍重建。
- `Bucket` 只在冻结后、容量大于存活数四倍且空闲超过 4096 个状态时移动整理。候选、排序、概率质量都保留；不是逐键无条件 `shrink_to_fit`。
- 词库元数据按需缓存，最多 256 个编码、1 MiB **估算负载**。超大单项绕过缓存，调用者仍可能暂时持有被淘汰项，因此不是全进程字节硬上限。别名 shared_ptr 同时保有底层只读字典映射。proper-prefix 另有 256 项有界布尔缓存。
- 同一代复用已评分完成池、部分路径评分和显示分段；证据升级不重放全部模型评分。自动上屏对证据、tracker 和可见路径建立借用视图索引，保留原向量顺序和浮点加总次序。
- observed-bigram 存在性复用原来的 4096 槽、128 KiB 精确键缓存，以独立键域区分概率查询。存在但概率为零不等于缺失；自定义模型和长字素仍绕过该缓存。

### 历史释放的范围

`retainCommittedHistory(raw, committedRaw)` 已接入 TSF 的异步和同步解码完成路径。它分批释放提交边界之前不再需要的位置桶，并保留最大码长/选重回看范围。

这里保留的是**全部竞争前沿**，不是选出一条最佳路径后重新起算。原始坐标、前沿的完整文本/分数/补充词状态/学习边界及边界链保留。编辑落到已释放范围以前时完整重建。

这解决了旧位置桶持续累积，但**没有把原始输入、前沿文本和边界链彻底重新定基，也不是无限连续输入的常量内存保证**。将历史压成“最后两个字”会改变隔离惩罚、词组边界、补充词和学习语义，本次不采用。

## 学习持久化与工作调度

`SentenceLearningAccumulator` 保存仅写线程使用的重放状态。普通追加只重放新事件；同一评分时刻仅重新生成变化编码的不可变分区，其他分区共享。时间变化更新衰减评分；撤销、清空、旧事件淘汰、时钟回拨和未来时间钳制变化均完整重放。原 `SentenceLearningSnapshot::build()` 保留独立完整实现用于交叉验证。

日志仍在跨进程锁下读取，并核对真实内容；最多缓存 1 MiB 原始字节对应的解析结果。较大日志不保留这份原始字节缓存。普通确认在持久化成功后只解析新增 E 记录，不再二次解析整份拼接日志。撤销/清空仍完整解析，以支持恢复先前滑出 10000 条窗口的旧事件。未知目标撤销标记、非法 UTF-16、重复 ID、断裂尾行和大批追加的窗口顺序都有回归覆盖。

**没有移除 fsync/FlushFileBuffers，没有提前发布未落盘学习分数，也没有宣称消除所有日志 I/O。** 重放状态和不可变索引共享存在内存/计算取舍；10000 条窗口淘汰时仍可能完整重建。

工作线程支持合作取消过时代的解码，在位置循环、批量扩展和结果构建阶段检查取消标记。取消后不发布半成品，不保留半更新缓存。同步确认可先取消旧任务再等解码锁；确认写入使用独立 FIFO，关闭服务时仍排空，不参与 latest-wins 取消。取消不是硬实时中断，不保证能立刻打断文件 I/O、一次排序或任意自定义模型调用。

### 可复现工作量与内存

同一合成 64 单字重码、三段 `aa`、Beam 2000 的冻结桶压力样本：存活状态都是 4065；审查基准容量 135233 个状态，优化版 6161 个状态。该 Linux 构建中状态数组缓冲区为 **16.51 → 0.75 MiB**（17309824 → 788608 字节）。这不是整个进程 RSS，不含模型、字符串和边界对象，也不等于扩展瞬间峰值。

连续 768 键且实际自动提交 382 次的单路径轨迹，释放历史版保留 **65 个位置**，未释放版 **769 个位置**；逐键候选/评分/证据及真实 session 自动提交相同。这个样本不代表复杂多分支总内存上界。

### CPU 探针

五次新进程交错配对，每进程预热后 20 次操作均值，再取五轮中位数。Linux `std::clock` CPU 时间；**不加载语言模型**，使用两项歧义码表、默认 Beam 2000、开启证据；追加一键为尚未完成的尾码。包含同步 decode/emit，不含准备和 TSF/UI，未清空系统缓存。

| 80 码锁定，追加一键 | 123.043 | 1.055 |

最后一行不包含日志读取/持久化，未达到窗口淘汰上限，不能代表每一次真实学习更新。锁定样本收益同时来自缓存复用和不再生成无效截断证据，不应描述为一个缓存技巧的纯收益，更不能外推生产模型或手机速度倍数。

## 2026-09-19 路径与模型布局优化

在前述缓存/增量修复之上，本轮进一步把剩余长句热点从“对象与字符串”层拆开：

- `State` 不再复制累计整句字符串；内部 boundary arena 保存父索引和映射词条 edge，
  state 只保留文本长度与 rolling hash。哈希碰撞必须经过完整路径逐字符比较，哈希不参与
  正确性判定。最终候选和需要学习的路径才物化完整字符串。
- 每个扩展不再 `make_shared<SentencePathBoundary>`；连续 arena 保存内部节点，候选发布时
  才按需构造并 memoize 公共 boundary 链。
- 提前上屏 prefix mass 使用预计算 prefix hash、unordered index 和 raw-length vector；
  incomplete-tail 只计算 confidence 所需字段。
- Windows 原生直接读取 TCSKNM02 分页模型；同源 TCSKNM01 继续兼容。打包模型 SHA/长度
  固定，mobile reader 对访问页逐项做边界和数值检查。
- TSF raw-change 判定不再构造两次完整 Snapshot；候选 renderer 的 DirectWrite/WIC/font
  collection 改为线程内有界复用。

行为验证：Linux ASan+UBSan review 173,040 checks、5,120 exact decoder snapshots、
163,440 learning replay comparisons、832 mapped-model snapshots均通过；Windows x64 和
Win32 分别通过 25,985 learning checks、173,040 review checks 以及 90 个 renderer cases。
ARM64/x64/Win32 均完成正式 Release 编译。
